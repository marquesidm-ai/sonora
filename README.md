# SONORA

Biblioteca pessoal de música, criada para uso particular.

## Primeira versão

- Interface inspirada em serviços modernos de streaming, com identidade própria.
- Layout responsivo para computador e celular.
- Busca por música, artista e álbum.
- Biblioteca pessoal.
- Favoritos.
- Playlists (estrutura inicial).
- Importação de arquivos de áudio pela interface.
- Player visual inicial.

## Próximas etapas

1. Reprodução real dos arquivos de áudio.
2. Persistência da biblioteca e favoritos.
3. Metadados e capas dos arquivos.
4. Playlists funcionais.
5. PWA para instalação no iPhone e Windows.
6. Empacotamento para iPhone/Windows, se necessário.
